# RFC-0022 — Conference Coffee-Break Protocol (CCBP)

## Abstract

This document specifies the Conference Coffee-Break Protocol (CCBP), an extension of the
Coffee-Break Protocol (CBP, RFC-0017) for multi-conference environments. CCBP addresses
cross-conference identity continuity, privacy model for informal networking across conference
series, and the unified identity framework required when attendees participate in multiple
structurally similar conferences.
